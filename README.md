Название проекта: HelperTripBot

Стартовая задача: создан эхо-бот, который повторяет сообщения за пользователем. При использовании команды "/help" бот
рассказывает, какие команды в нем реализованы.

Пример диалога:

Пользователь: "/start"

Бот: "Привет, я эхо-бот, отправь мне сообщение и я повторю его за тобой!"

Пользователь: "Привет"

Бот: "Вы ввели «Привет»"

Пользователь: "/help"

Бот: "Привет, я Эхо-Бот

/start - начало работы

/help - показать все доступные команды."

Как подключить файл c properties?: В папке main переходим в папку resources создаем файл tgBot.properties. Далее заполняем его настоящими данными, пользуясь примером из файла tgBot.properties.example.

Как запустить?: Запустить бота можно в классе TgBotMain, нажав кнопку выполнения программы. Далее открываем бота в тг и нажимаем команду "/start".
