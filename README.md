Название проекта: HelperTripBot

Телеграм-бот — помощник в путешествиях по городам России.
Показывает краткую справку о городе и прогноз погоды на выбранные даты.

Для запуска требуется Java 25 и Maven.

Как подключить файл c properties?: В папке main переходим в папку resources создаем файл tgBot.properties. Далее заполняем его настоящими данными, пользуясь примером из файла tgBot.properties.example.

Как запустить?: Запустить бота можно в классе TgBotMain, нажав кнопку выполнения программы. Далее открываем бота в тг и нажимаем команду "/start".

Задача 1. Эхо-бот
Бот возвращает текст пользователя, `/help` рассказывает о командах.

Задача 2. Цель: реализовать меню тг-бота и список команд, которые будут доступны пользователю после выбора конкретного
города, а также поддержку множества диалогов с разными пользователями. По команде /start - пользователю предлагается
ввести название города в России, про который он хочет узнать. После чего пользователю будет представлен список команд, а
из этого списка будут реализованы три команды: /weather - узнать погоду в выбранном городе, /back - возврат к списку
команд, /about_city - краткая сводка об этом городе.

Что умеет бот на данном этапе развития проекта:

- `/start` — начать, бот просит ввести название города
- `/help` — инструкция по использованию бота
- После выбора города доступны кнопки: **about city** (справка о городе), **weather** (погода), **back** (назад)
- Каждый пользователь ведёт свой диалог независимо от других

Города берутся из `city_info.csv`; если города нет в каталоге, бот ответит «Информации о городе не найдено».

Примеры диалогов

**Погода**

    П: /start
    Б: Привет, я бот — помощник в путешествиях. В какой город вы хотели бы отправиться?
    П: Казань
    Б: Выберете категорию для города Казань: [about city] [weather] [back]
    П: (кнопка weather)
    Б: На какие даты вас интересует погода? Напишите период в формате дд.мм - дд.мм. Длина периода не более 14 дней.
    П: 22.10 - 29.10
    Б: Погода в городе Казань с 22.10 по 29.10:
       22.10: +3...+8°C, облачно
       ...
    П: 22.10 - 15.11
    Б: Период слишком длинный. Выберите период не более 14 дней.

**О городе и назад**

    П: Москва
    Б: Выберете категорию для города Москва: [about city] [weather] [back]
    П: (кнопка about city)
    Б: Москва — Столица России ... (название и статус, население и площадь, описание, климат, факты)
    П: (кнопка back)
    Б: Выберете категорию для города Москва: ...
